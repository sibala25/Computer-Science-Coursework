# Introduction to Computer Science II (CS32)

Selected UCLA CS32 coursework, organized into homework and programming projects.

## Homework

- **[HW1](Homework/HW1/):** Set abstractions and implementations, including a `PayerSet` wrapper and revised Set implementation. Parts 1, 4, and 5.
- **[HW2](Homework/HW2/):** Maze traversal using stack and queue techniques; expression evaluation. Parts 1, 3, and 5.
- **[HW3](Homework/HW3/):** Linked lists, linear operations, maze search, and tree algorithms. Parts 1–4.
- **[HW4](Homework/HW4/):** List/vector analysis, Set implementation, and sorting algorithms. Parts 1, 2, 4, and 7.

The archive only contains the parts listed above; gaps in numbering are not necessarily missing submissions.

## Projects

- **[Project 1](Projects/Project1/):** City simulation game, with classes for the game world, players, and history.
- **[Project 2](Projects/Project2/):** Set implementation and tests using dynamic memory management.
- **[Project 3](Projects/Project3/):** Temple-based game with actors, game objects, and a game loop.
- **[Project 4](Projects/Project4/):** Hash-table-based file revision algorithm. `revision.cpp` is taken from the original `finalproj4.zip` submission.
