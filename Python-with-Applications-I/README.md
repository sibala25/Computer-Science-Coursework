# Python with Applications I

Undergraduate coursework from *Python with Applications I* (UCLA). This folder preserves the original Jupyter notebook submissions alongside PDF exports, so readers can view both the assignment context and the submitted work.

| Homework | Topics |
| --- | --- |
| [HW1](HW1/) | Python fundamentals, strings, collections, and iteration |
| [HW2](HW2/) | Text processing and Markov language models |
| [HW3](HW3/) | Data retrieval and PageRank |
| [HW4](HW4/) | NumPy and array computations |
| [HW5](HW5/) | Data visualization and faceted histograms |
| [HW6](HW6/) | Data analysis, Gapminder, and visualization |
| [HW7](HW7/) | Equity and algorithmic bias in data analysis |

Each homework folder contains a notebook (`.ipynb`) and a PDF export of the submitted assignment. The notebooks and PDFs are archival student work, not updated or independently retested software. Some embedded assignment prompts and starter cells were supplied by course staff. Share the PDFs publicly only if course sharing rules permit it.

**Palmer Penguins project:** This course also included a group classification project using the Palmer Penguins dataset. It is documented separately in the portfolio rather than duplicated here.
