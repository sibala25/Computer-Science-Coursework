# Undergraduate Coursework

A collection of selected undergraduate coursework completed at the **University of California, Los Angeles (UCLA)** as part of my B.S. in Cognitive Science, minor in Data Science Engineering, and specialization in Computing.

This repository documents my academic foundation in mathematics, statistics, computer science, data science, and machine learning through programming assignments, mathematical problem sets, and applied projects.

## Repository Organization

Each course has its own folder containing selected assignments and a README describing the included work. Depending on the course, materials include:

- **Jupyter notebooks and source code** for programming assignments.
- **PDF solutions** for mathematical and theoretical problem sets.
- **Project write-ups** documenting implementations, analyses, and results.

## Notes

This repository is an archive of undergraduate coursework rather than a collection of production-ready applications. Some assignments use instructor-provided starter code, datasets, or dependencies and may not run independently without the original course environment.

Files are preserved primarily to demonstrate academic work and technical preparation. Individual course READMEs provide additional details about the assignments and any relevant limitations.
