# Introduction to Computer Science I (CS 31)

Selected original C++ coursework from UCLA's Introduction to Computer Science I. The six homework sets are organized by assignment, including the Beetle Game (Project 6).

| Assignment | Contents |
| --- | --- |
| [HW1](HW1/) | Introductory programming and debugging exercises |
| [HW2](HW2/) | Payment calculations and conditional logic |
| [HW3](HW3/) | String validation and processing |
| [HW4](HW4/) | Array operations |
| [HW5](HW5/) | Plane flight and frequent-flyer account classes |
| [HW6 — Beetle Game](HW6/) | Object-oriented C++ game with a beetle model, game logic, dice, drawing, and a test driver |

## Notes

- Source code is from the original course submissions, apart from redaction of the student ID. Formatting and implementation logic were not otherwise modified.
- HW6 was completed using instructor-provided starter files. The repository preserves the available course project files and does not claim every component was written from scratch.
- Compiled binaries, duplicate copies, and Xcode project metadata are excluded.
- The code is archival coursework and has not been independently rebuilt or fully tested here. HW5's original driver may need corrections to run.
